Chapter 12: Driver Functions

Read the primer: Driver Functions

The Built-in Toolbox

The LPC driver comes with a library of built-in functions called efuns. You will use these constantly, they are the workhorses for processing text, crunching lists, and managing data.

The Ones You Will Use Most

Strings:

  • explode("a,b,c", ",") → ({"a","b","c"}), split text
  • implode(({"a","b","c"}), ",") → "a,b,c", join text
  • capitalize("goblin") → "Goblin"
  • sprintf("HP: %d", 100) → "HP: 100", formatted output

Arrays:

  • sizeof(arr), how many elements
  • filter(arr, func), keep matching elements
  • sort_array(arr, func), sort with a comparison function

Mappings:

  • m_indices(map), all keys as an array
  • m_values(map), all values as an array
  • map_delete(map, key), remove an entry

Exercise 12.1: String Toolbox Apprentice

Write a utility object containing three string manipulation functions.

Requirements

  • Implement string title_case(string s):
    • Capitalizes the first letter of every word in the string
    • Use explode() to split on spaces, capitalize() each word, then implode() to rejoin
    • Example: "hello world" becomes "Hello World"
  • Implement int word_count(string s):
    • Returns the number of words in the string
    • Use explode() to split on spaces, then sizeof()
    • Handle edge case: empty string "" should return 0
  • Implement string pad_right(string s, int width):
    • Returns the string padded with trailing spaces to reach width
    • Use sprintf("%-*s", width, s) for the formatting
    • If the string is already longer than width, return it unchanged

File to create: exercises/ch12_driver_functions/ex01_string_funcs.c

Compare: ex01_string_funcs_solution.c

Hints (click to reveal)
  1. explode("hello world", " ") returns ({"hello", "world"}). It splits a string into an array by the given delimiter.
  2. capitalize("hello") returns "Hello". It only capitalizes the very first character of the string.
  3. implode(array, " ") is the reverse of explode, it joins an array of strings back together with the given delimiter.
  4. The sprintf format "%-*s" left-aligns a string in a field of variable width. The * means the width comes from the next argument: sprintf("%-*s", 10, "hi") produces "hi ".

Exercise 12.2: Array Operations Journeyman

Write a utility object that stores an array of monster levels and provides functions to analyze and transform the data.

Requirements

  • Store a global int *levels array set in create() with at least 8 values (e.g., ({5, 12, 3, 18, 7, 25, 14, 9}))
  • Implement int average_level():
    • Returns the integer average of all values in levels
    • Use a foreach loop to sum the values, then divide by sizeof(levels)
  • Implement int *filter_above(int threshold):
    • Returns a new array containing only levels strictly greater than threshold
    • Use the filter() efun with a function or closure
  • Implement int *sort_descending():
    • Returns a copy of levels sorted from highest to lowest
    • Use sort_array() with a closure comparator: (: $2 - $1 :)

File to create: exercises/ch12_driver_functions/ex02_array_funcs.c

Compare: ex02_array_funcs_solution.c

Hints (click to reveal)
  1. foreach syntax in LPC: foreach (int val : levels) { total += val; } iterates over every element in the array.
  2. filter(array, function) keeps only elements for which the function returns nonzero. You can use a closure: filter(levels, (: $1 > threshold :)) or define a helper function.
  3. sort_array(array, closure) sorts in place. The closure receives two elements and should return positive if the first should come after the second. For descending: (: $2 - $1 :).
  4. Remember that integer division in LPC truncates (rounds toward zero), so 93 / 8 gives 11, not 11.625.

Exercise 12.3: Mapping Utilities Journeyman

Write a utility object with two mapping manipulation functions.

Requirements

  • Implement mapping invert_mapping(mapping m):
    • Returns a new mapping with keys and values swapped
    • Given (["a":1, "b":2, "c":3]) return ([1:"a", 2:"b", 3:"c"])
    • Use m_indices() or foreach to iterate the original mapping
  • Implement mapping merge_mappings(mapping a, mapping b):
    • Returns a new mapping that combines both a and b
    • Where keys overlap, values from b overwrite values from a
    • Given (["hp":100, "sp":50]) and (["sp":75, "mp":30]), return (["hp":100, "sp":75, "mp":30])
    • Do not modify the original mappings

File to create: exercises/ch12_driver_functions/ex03_mapping_funcs.c

Compare: ex03_mapping_funcs_solution.c

Hints (click to reveal)
  1. m_indices(m) returns an array of all keys in mapping m. You can loop over these keys and read m[key] to get each value.
  2. To build a new mapping, start with mapping result = ([]); and then assign into it: result[new_key] = new_value;.
  3. For merge_mappings, one approach: copy all of a into the result first, then copy all of b (which naturally overwrites any conflicts).
  4. The foreach syntax for mappings is: foreach (mixed key, mixed val : m) { ... } which gives you both the key and value on each iteration.

Capstone Connection — Phase 2: Atmosphere

Driver functions are the tools you will reach for constantly when building your capstone area. String formatting with sprintf() creates polished output, filter() and sort_array() help manage monster inventories and loot tables, and mapping operations power everything from exit lists to stat tracking.
