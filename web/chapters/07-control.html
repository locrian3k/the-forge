Chapter 7: Control Structures

Primer: Control Structures

Directing the Flow

Code runs top to bottom, unless you tell it otherwise. Control structures let you branch, loop, and jump.

Branching: if/else chains handle decisions. switch/case is cleaner when testing one value against many options. Switch has a quirk: cases fall through to the next unless you add break;. This is sometimes a bug, sometimes intentional — Exercise 7.2 explores both.

Loops: LPC has three kinds:

  • for, when you need an index counter
  • foreach, cleanest way to walk through arrays and mappings
  • while, when the exit condition is not index-based

Choosing the right loop makes your code clearer. foreach is almost always the best choice for arrays and mappings in LPC.

Read the Control Structures chapter of the primer before starting.

Exercise 7.1: Branch Logic Apprentice

Implement the same weather-description logic twice, once using if/else chains and once using switch/case.

Requirements

  • Implement string describe_weather_if(int code) using if/else:
    • 0 returns "clear"
    • 1 returns "cloudy"
    • 2 returns "rainy"
    • 3 returns "stormy"
    • 4 returns "snowy"
    • Any other value returns "unknown"
  • Implement string describe_weather_switch(int code) using switch/case with the same mappings
  • Each case must have a break; statement (no fall-through)
  • Use default: for the unknown case
  • Both functions must return identical results for the same input

File to create: exercises/ch07_control/ex01_branch_logic.c

Hints (click to reveal)
  1. An if/else chain: if (code == 0) ... else if (code == 1) ... ending with a final else.
  2. LPC switch syntax: switch (code) { case 0: ...; break; ... }
  3. Declare a local string result;, assign in each branch, and return at the end.
  4. Test with values 0 through 5 to verify both functions are equivalent.

Exercise 7.2: Switch Fall-Through Journeyman

Practice using intentional switch fall-through.

Requirements

  • Implement string damage_message(string type) using a switch with intentional fall-through:
    • "fire" falls through to "acid", both return "It burns!"
    • "ice" falls through to "lightning", both return "A shocking chill!"
    • "poison" returns "You feel ill."
    • default returns "Ouch!"
  • Comment every intentional fall-through with // fall through

File to create: exercises/ch07_control/ex02_fall_through.c

Hints (click to reveal)
  1. Fall-through means omitting break; so execution continues into the next case. Place the empty case first: 
    case "fire":   // fall through
case "acid":
  result = "It burns!";
  break;
  2. In LPC, switch works with strings as well as integers.
  3. Commenting fall-through signals intent, without it, another coder might think you forgot the break;.
  4. Test with all six inputs: "fire", "acid", "ice", "lightning", "poison", and something like "blunt".

Exercise 7.3: Loop Workshop Apprentice

Practice the three main loop constructs in LPC, for, foreach, and while.

Requirements

  • In create(), set up two global variables:
    • string *monsters, an array of at least 4 monster names
    • mapping levels, a mapping of monster_name : level (int)
  • Implement string list_monsters() using a for loop:
    • Iterate over the monsters array by index
    • Return a numbered list, e.g. "1. goblin\n2. orc\n3. troll\n4. dragon\n"
  • Implement int total_levels() using a foreach loop:
    • Iterate over the levels mapping
    • Return the sum of all level values
  • Implement string first_above(int threshold) using a while loop:
    • Walk through the monsters array
    • Return the name of the first monster whose level exceeds threshold
    • Return "none" if no monster qualifies

File to create: exercises/ch07_control/ex03_loops.c

Hints (click to reveal)
  1. for loop syntax: for (int i = 0; i < sizeof(array); i++). Use sizeof() for array length.
  2. foreach over a mapping: foreach (string key, int val in mapping).
  3. while loop: initialize an index before the loop, check the condition, increment inside the body. Return early when you find a match.
  4. Array indexing is zero-based, but your numbered list should start at 1.

Capstone Connection: Phase 1 — The Foundation

Control structures power every game mechanic: branching logic determines what happens when a player examines an item, loops process rooms on reset, and switch statements route commands. You will use all three loop types in your capstone area.
