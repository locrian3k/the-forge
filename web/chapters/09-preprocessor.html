Chapter 9: Preprocessor

Primer: Preprocessor

Code Before the Code Runs

The preprocessor runs before compilation. It does simple text substitution, no types, no logic, just find-and-replace.

#define TO this_object() means: everywhere the compiler sees TO, it swaps in this_object(). That is all defines do.

#include "defs.h" means: copy the entire contents of defs.h into this file at this point. This is how areas share path constants, change a path in the header, and every file that includes it picks up the change.

Conditional Compilation

#ifdef, #ifndef, and #if let you include or exclude code at compile time. Common uses: enabling debug output during development, toggling features by version number, and include guards that prevent a header from being processed twice.

Exercise 9.1: Define and Include Apprentice

Create a header file with path defines, string constants, and a utility macro.

File 1: ex01_my_defs.h

  • Define MY_PATH as a base path string
  • Define MY_ROOMS as MY_PATH + "rooms/"
  • Define MY_MOBS as MY_PATH + "mobs/"
  • Define AREA_NAME as a string constant
  • Define a MAX(a, b) utility macro using the ternary operator

File 2: ex01_define_include.c

  • #include "ex01_my_defs.h" to pull in all defines
  • In create(), use every define at least once
  • Implement query_area_name() returning AREA_NAME
  • Implement query_room_path() returning a path built with MY_ROOMS
  • Implement query_mob_path() returning a path built with MY_MOBS
  • Implement query_max_test() returning MAX(5, 10)

Files to create: exercises/ch09_preprocessor/ex01_my_defs.h and exercises/ch09_preprocessor/ex01_define_include.c

Hints (click to reveal)
  1. Defines are simple text substitution. #define MY_PATH "/players/me/myarea/" replaces every occurrence before compilation.
  2. You can build defines from other defines: #define MY_ROOMS (MY_PATH + "rooms/") works because MY_PATH is substituted first. Wrap concatenation in parentheses to prevent precedence issues.
  3. The MAX macro needs parentheses around parameters: #define MAX(a, b) ((a) > (b) ? (a) : (b))
  4. Use quotes "ex01_my_defs.h" (not angle brackets) because the header is in the same directory.

Exercise 9.2: Conditional Compilation Journeyman

Use conditional preprocessor directives to create a header with an include guard and a code file that changes behavior based on compile-time defines.

File 1: ex02_conditional.h

  • Add an #ifndef / #define / #endif include guard
  • Define a VERSION number (e.g., 2)
  • Define an AREA_TITLE string constant
  • Optionally define DEBUG (show how to toggle by commenting/uncommenting)

File 2: ex02_conditional.c

  • Include ex02_conditional.h
  • Use #ifdef DEBUG for conditional debug output:
    • When defined: query_debug_info() returns a debug string
    • When not defined: query_debug_info() returns "no debug"
  • Use #if VERSION >= 2 for conditional features:
    • Version 2+: query_feature() returns "enhanced"
    • Below 2: query_feature() returns "basic"
  • Implement query_version() returning the VERSION number
  • Implement query_title() returning AREA_TITLE

Files to create: exercises/ch09_preprocessor/ex02_conditional.h and exercises/ch09_preprocessor/ex02_conditional.c

Hints (click to reveal)
  1. Include guard pattern: 
    #ifndef __MY_CONFIG_H__
#define __MY_CONFIG_H__
... all your defines here ...
#endif
  2. #ifdef DEBUG checks whether DEBUG is defined at all, even #define DEBUG 0 counts as "defined."
  3. #if VERSION >= 2 evaluates the numeric value, letting you write version-dependent code.
  4. To toggle DEBUG, comment out #define DEBUG with //. When deployed to the MUD and compiled, the #ifdef DEBUG block would be excluded, changing the behavior of query_debug_info().

Capstone Connection: Phase 1 — The Foundation
