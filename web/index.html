The Forge — LPC Exercises for 3Kingdoms

Companion exercises for the 3K Code Primer

Welcome to The Forge, a hands-on exercise curriculum for learning LPC programming on 3Kingdoms MUD. Each chapter pairs with a section of the 3K Code Primer, giving you practical exercises to reinforce every concept you read about.

Every exercise comes with clear requirements, helpful hints you can reveal when stuck, and solution files you can compare against to check your work. Work through them at your own pace, and watch your skills grow from basic objects to complete dungeon areas.

Getting Started

1. Download the Exercise Files

To work through the exercises, you need a local copy of The Forge files. Download them using either option:

Download ZIP — extract to a folder on your computer.

Prefer git? The GitHub repository is available for offline access or if you already use git in your workflow.

2. Know Your Folders

The Forge is organized into folders you will work with throughout the curriculum:

  • exercises/ — Starter files with TODO comments for you to fill in. Each chapter has its own subdirectory (e.g., exercises/ch01_intro/). Open these in your text editor and write your code.
  • solutions/ — Fully commented reference implementations. When you finish an exercise, compare your work against the matching solution file.
  • reference/ — Quick-reference cheatsheets you can look up while working.
  • capstone/ — A multi-phase final project where you build a complete dungeon area. Templates and phase guides are inside.

Each exercise directory also contains a defs.h file. This is a shared header that defines common shortcuts used across all exercises. You do not need to create or modify it — just know that when your code says #include "defs.h", it pulls in those shortcuts automatically. Chapter 1 explains what is inside it.

Two Learning Tracks

Exercises come in two difficulty tiers. You can do just one track or both, it is up to you.

Apprentice

Core exercises that cover the fundamentals. If you are new to LPC or programming in general, start here. Each Apprentice exercise focuses on one concept with minimal complexity.

Journeyman

Deeper challenges that combine multiple concepts, debug existing code, or tackle real-world MUD patterns. Take these on once you are comfortable with the basics, or if you already have programming experience.

The Capstone Project

Build Your Own Dungeon Area

The Forge culminates in a multi-phase capstone project where you build a complete, working dungeon area for 3Kingdoms. As you progress through the chapters, each set of exercises feeds into a phase of the capstone:

  • Phase 1: The Foundation (Chapters 1-9), Core language skills
  • Phase 2: Atmosphere (Chapters 10-14), Rooms, objects, and structure
  • Phase 3: Combat (Chapters 15-17), Weapons, armor, and monsters
  • Phase 4: Integration (Chapters 18-19), Tying it all together

By the time you finish, you will have a fully playable dungeon area that you built from scratch, exercise by exercise.

Progress Tracking

Each exercise has a checkbox that saves your completion state in your browser's local storage. Your progress persists between visits, no account needed. Look for the checkboxes on each chapter page.
